# Automated Daily Hindi Mystery YouTube Shorts

This project autonomously creates, narrates, renders, and uploads a daily serialized Hindi mystery Short to YouTube using GitHub Actions.

## Project Structure

```text
hindi-mystery-shorts/
├── .github/
│   └── workflows/
│       └── daily.yml          # GitHub Actions daily schedule (09:00 IST)
├── make_short.py              # Script that generates script, TTS audio, video & meta
├── upload_youtube.py          # Script that uploads output/short.mp4 to YouTube
├── get_refresh_token.py       # One-time helper to generate YouTube OAuth refresh token
├── requirements.txt           # Python dependencies
└── series.json                # State file storing story arc & past parts (auto-committed)
```

---

## 1. Setup YouTube Data API v3 & OAuth Credentials

1. Go to the [Google Cloud Console](https://console.cloud.google.com/).
2. Create a new project or select an existing one.
3. Enable **YouTube Data API v3** under **APIs & Services > Library**.
4. Configure the **OAuth Consent Screen**:
   - User Type: **External** (in Testing mode is fine; add your YouTube Google account as a Test User).
   - Scopes: Add `https://www.googleapis.com/auth/youtube.upload` and `https://www.googleapis.com/auth/youtube`.
5. Create OAuth 2.0 Client ID:
   - Go to **APIs & Services > Credentials > Create Credentials > OAuth client ID**.
   - Application type: **Desktop app**.
   - Copy your **Client ID** and **Client Secret**.

---

## 2. Generate YouTube Refresh Token

Run the helper script locally on your PC:

```bash
pip install -r requirements.txt
python get_refresh_token.py
```

Follow the prompt, log in with your YouTube Google account, grant permission, and the script will display your `YT_REFRESH_TOKEN`.

---

## 3. Configure GitHub Repository Secrets

In your GitHub repository, navigate to **Settings > Secrets and variables > Actions** and add:

| Secret Name | Description |
|---|---|
| `ANTHROPIC_API_KEY` | Your Anthropic Claude API Key |
| `YT_CLIENT_ID` | Google OAuth Client ID |
| `YT_CLIENT_SECRET` | Google OAuth Client Secret |
| `YT_REFRESH_TOKEN` | Refresh token generated by `get_refresh_token.py` |

> [!NOTE]
> In GitHub repository settings under **Settings > Actions > General > Workflow permissions**, select **"Read and write permissions"** and check **"Allow GitHub Actions to create and approve pull requests"** so the bot can commit updated `series.json`.

---

## 4. How It Works Daily

1. Every day at **03:30 UTC (09:00 IST)**, GitHub Actions triggers `daily.yml`.
2. `make_short.py` reads `series.json`, writes the next episode beat using Claude, generates natural Hindi voiceover using `edge-tts`, and produces a 1080x1920 video (`output/short.mp4`) with animated headlines and English subtitles.
3. `upload_youtube.py` uploads the Short with tags, audience cliffhanger question, and privacy setting (default `private`, change to `public` once satisfied).
4. If the upload succeeds, `output/series_next.json` is copied to `series.json` and committed back to the repository.
